# Risk & Compliance Analytics Lab

This repository is a hands-on analytics portfolio focused on using data to solve operational and risk-related business problems.

The projects combine SQL, Power BI and analytical thinking across topics such as KYC workload, customer risk, overdue reviews and decision support.

## Current Project

**KYC Workload & Risk Dashboard** — a synthetic AML/KYC dataset used to analyse workload, open cases, risk levels and overdue reviews.
